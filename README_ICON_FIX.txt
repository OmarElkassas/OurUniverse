O&H IPHONE ICON FIX

Upload apple-touch-icon.png directly to the repository root. The additional size-specific icon files can also be uploaded. Do not place them inside another folder.

On the iPhone showing the black O icon:
1. Delete the existing O&H Home Screen shortcut.
2. Open the website in Safari after the deployment completes.
3. Refresh the page.
4. Tap Share > Add to Home Screen and add it again.

The already installed shortcut will not replace its cached icon automatically.
